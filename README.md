# PeraGo

PeraGo wallet prototype with:
- Mobile-number registration
- Demo 6-digit OTP generation and verification
- Name/email/number registration
- 4-digit PIN setup
- PIN-based login
- Firebase Authentication + Firestore

IMPORTANT: The OTP shown inside the registration screen is a DEMO OTP, not an SMS OTP. Do not use this implementation for real financial transactions or production authentication. Production should use a trusted server-side OTP/SMS provider, hashed PINs, rate limiting, secure Firestore rules, and server-side authorization.
