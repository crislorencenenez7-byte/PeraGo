# PeraGo

Modern Firebase-backed PeraGo wallet prototype/PWA.

## Setup
1. Put the project files in your GitHub repository.
2. Keep your Firebase project configuration in `firebase-config.js`.
3. Enable Firebase Authentication and Firestore.
4. Deploy with Firebase Hosting, GitHub Pages, or another static host.

> This is a prototype wallet UI. It is not a real-money payment rail. Real financial transactions require server-side authorization, secure Firestore rules, validation, fraud controls, and an appropriate payment provider.
